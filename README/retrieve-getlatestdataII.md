# node-red-dashboard-2-ia-cloud - retrieve-getlatestdataII

## 名称

retrieve-getlatestdataIIノード

## 機能概要

このノードは指定したDynamoDBから直近1件分のiacloudオブジェクトを取得し、設定した出力形式に応じたデータへ変換して出力します。

このノードを使用するには、DynamoDB操作ユーザの情報が必要になります。ユーザ情報は別途発行・取得する必要があります。

## プロパティー

取得するデータに応じて以下のパラメータを設定します。

- ### 名前

  フロー上で表示するノード名を設定します。

- ### 接続先CCS

  ia-cloud CCS接続設定ノードを設定します。

- ### テーブル名

  検索を行うテーブル名を設定します。

- ### オブジェクトキー

  検索を行うデータのobjectKeyを設定します。

- ### 項目設定

  出力結果のdataName部分の表示名を変更することができます。
  対応するdataNameと出力したい表示名を入力します。
  表示名が未入力の場合は、dataNameをそのまま出力します。

- ### 繰り返し

  繰り返し処理を行う場合は本項目を設定します。
  設定後、繰り返し間隔を設定します。

- ### 表示桁数

  取得データの表示桁数の設定をします。
  小数第3位～100の位、丸めなしの設定が可能です。

- ### 出力形式

  出力形式を以下から選択し、設定します。
  - グラフ用データ
  - 数値変換用データ
  - ia-cloudオブジェクト

  ※チャートへの時系列データの入力は「ノード：[retrieve-getchartdataII](https://github.com/ia-cloud/node-red-dashboard-2-ia-cloud/blob/master/README/retrieve-getchartdataII.md)」を使用してください。

## 出力メッセージ

  入力されたiacloudオブジェクトをdashborad - chartへ入力する際の形に変換した結果が出力されます。
  項目設定に指定されたdataNameのデータが存在しなかった場合、該当部分にはnullが出力されます。

### (1) グラフ用データ

  単一の数値を出力します。
  以下に例を示します。

    22.2

  ※表示名が設定されている場合は、UIラベルとして使用されます。

### (2) 数値変換用データ

  複数のデータを配列形式で出力します。
  以下に例を示します。

    [
        [
            "温度ch1",
            22.2,
            "℃"
        ],
        [
            "TEMP-M01temp2",
            18.2,
            "℃"
        ],
        [
            "温度ch3",
            26.3,
            "℃"
        ],
        [
            "TEMP-M01temp4",
            19.6,
            "℃"
        ]
    ]

### (3) ia-cloudオブジェクト

  取得したia-cloudオブジェクトのうち、指定したdataNameのみを出力します。
  以下に例を示します。

    {
      "objectType": "iaCloudObject",
      "objectContent": {
        "contentData": [...]
        }
      }
